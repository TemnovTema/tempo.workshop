# Tempo — план веб-скринкаста

Статус: только планирование и подготовка. Видео не записано и не смонтировано.

Источник: https://tempo-workshop-tema-team.vercel.app/prototype/#today

Согласованные ограничения: только веб-версия; горизонтальный ролик; 15–20 секунд. Предлагаемый хронометраж — 18 секунд, формат — 1920×1080, 60 кадров/с. Звук и окончательный стиль ещё не выбраны.

## Раскадровка — предложение

| Время | Содержание | Движение камеры |
| --- | --- | --- |
| 0–2,5 с | Общий вид «Сегодня», ритм дня | Мягкий въезд от общего вида к кольцу состояния, масштаб 1 → 1,15 |
| 2,5–6 с | Переход в «Состояние», движение ползунка энергии; меняется выражение лица | Приближение до 1,4–1,5 к лицу и ползунку, короткая остановка на результате |
| 6–11 с | Календарь; выбор задачи и открытие её карточки | Отъезд для контекста, затем приближение к выбранной задаче |
| 11–16 с | «Практики» → запуск дыхательной практики | Плавный переход к анимации дыхания; дать ей прожить несколько секунд |
| 16–18 с | Отъезд, финальный кадр с Tempo | Короткая подпись «В своём ритме»; возможность зациклить ролик |

Три демонстрируемых действия: изменить отметку энергии, открыть задачу, запустить практику. Это монтаж коротких фрагментов разных сценариев, а не непрерывное прохождение всех шагов приложения.

## Визуальное направление

- Спокойное продуктовое демо, соответствующее мягкому интерфейсу Tempo.
- Плавный курсор с естественным замедлением у цели; неброское кольцо в момент клика.
- Камера сначала останавливается у цели, затем происходит клик; пауза на результате перед следующим движением.
- Зумы примерно 1,15–1,5; длительность переходов 0,65–0,9 с; не обрезать важные элементы и заголовки.
- Фон в цветах приложения, небольшие поля и мягкая тень вокруг окна.
- Возможный визуальный мотив: круг ритма дня → лицо состояния → круг дыхательной практики.
- Небольшое размытие только при быстрых монтажных переходах; в остановках текст резкий.
- Озвучка не предусмотрена в черновом предложении. Лёгкая музыка и тихие звуки действий — отдельное решение.

## Что проверено

Локальная версия проекта просмотрена в Chrome; первый экран сохранён в `initial.png`. Исходники основных сценариев изучены. Опубликованная ссылка в отдельной браузерной сессии перенаправляет на вход Vercel, поэтому соответствие опубликованного сайта локальной копии пока не подтверждено. Настройки доступа не менялись.

На машине доступны Chrome, Playwright, Node.js и FFmpeg. Установка пакетов для текущей подготовки не понадобилась.

## Технические заметки для будущей записи

- Начальный адрес должен содержать `#today`; адрес без hash открывает регистрацию.
- Навигация: `[data-view="checkin"]`, `[data-view="calendar"]`, `[data-view="practices"]`.
- Ползунок энергии: `#energyRange`. Использовать реальное перетаскивание с событием `input`.
- Карточка задачи: `.calendar-event[data-pomodoro-task-name="Макет главного экрана"]`.
- Дыхательная практика: `.featured-practice [data-practice-start]`. Проверить точное название и длительность фаз на опубликованной версии перед записью.
- На локальном первом экране кнопка «Начать фокус» открывает старый оверлей со статическим таймером. Этот фрагмент не включён в предложенный сценарий.
- Сохранение проверки состояния не пересчитывает план дня; не показывать и не описывать такую причинную связь.
- Перед записью дождаться загрузки шрифта иконок. Настроить размер окна для читаемого интерфейса; записывать с запасом разрешения для зумов.
- До записи проверить опубликованный сайт в доступной авторизованной сессии. Не создавать ссылки доступа и не менять защиту проекта в рамках подготовки.
