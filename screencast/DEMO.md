# Демонстрационные данные

Открыть http://127.0.0.1:4174/prototype/?demo=1#calendar .

Запуск из корня проекта: `python3 -m http.server 4174 --bind 127.0.0.1`.
Порт 4174 отделяет хранилище демо от основного локального приложения на 4173.

При первом открытии пустого хранилища создаются 34 задачи на текущую московскую неделю. Повторное открытие сохраняет правки и не заменяет календарь. Даты после первого заполнения не сдвигаются автоматически.

Цвет берётся из настроек проекта во всех трёх видах календаря: Tempo — коралловый, учёба — сиреневый, здоровье — зелёный; задачи команды — голубые. Изменение цвета проекта меняет его карточки при перерисовке.

Проверка: день и неделя в браузере; 43 автоматических теста проходят, включая корректность демоданных и сохранение существующего календаря. Скриншот: audit/demo-calendar.jpg.
